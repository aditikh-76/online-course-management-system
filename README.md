# Online Course Management System

This is a beginner-level Online Course Management System homepage made using **HTML, CSS, and JavaScript**.

## Features

* Simple navigation bar
* Home page
* Popular courses section
* Course cards
* Enroll Now button
* Login button
* About section
* Contact section
* Basic JavaScript interactions

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```text
Online-Course-Management-System/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone this project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. You can also use the **Live Server** extension in VS Code.
